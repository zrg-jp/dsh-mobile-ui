# サイドバーを開く右スワイプは画面左半分まで反応させる

- Status: superseded by ADR-20261026-1416
- Date: 2026-10-24
- Task: T302 の追補（ADR-20261023-1750 の発火域の決定のみ差し替え。実装方式・他のガードは 1750 のまま）

## Context

実機利用で「一覧（サイドバー）を出すスワイプは画面真ん中あたりで反応してほしい」との
フィードバック。左端 28px 起点は片手持ちでは狙いにくい。

## 選択肢

1. サイドバーを開く右スワイプだけ起点を画面左半分（x ≤ innerWidth/2）へ拡大し、
   右パネルから「戻る」は左端 28px のまま維持する。
2. 両方の右スワイプを左半分へ拡大する。

## 決定

選択肢 1。

## 理由

- サイドバーを開く場面はチャット表示中で、横スクロール祖先・編集領域・テキスト選択の
  ガードが既にあり、起点拡大による誤発火面が小さい。
- 右パネル（diff 等）は横パン操作が主で、起点拡大は誤って畳む事故が増えるため維持。
- ユーザーの要望は「一覧を出すスワイプ」に限定されている。

## 検証

- iPhone PWA 実機で、画面中央付近からの右スワイプでサイドバーが開き、
  右パネル表示中は従来どおり左端からのみ戻ることを確認後に accepted。
- 2026-10-24: ユーザーが iPhone PWA 実機で「サイドバーは良し」と確認。
  なお同報告で判明した「diff 上では戻るが発火しない」は横スクロールガードの
  全方向適用が原因で、右スワイプに限り全スクローラが左端（scrollLeft=0）なら
  発火を許す追補を同日実装（この決定の範囲外、1750 のガード詳細の調整）。
