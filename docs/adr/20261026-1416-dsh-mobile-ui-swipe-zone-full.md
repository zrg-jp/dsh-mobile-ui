# サイドバーを開く右スワイプは画面全体を起点にできる

- Status: accepted
- Date: 2026-10-26
- Supersedes: ADR-20261024-0210（発火域の決定のみ。右パネルから戻る操作の左端 28px 限定は維持）

## Context

ADR-20261024-0210 でサイドバーを開く右スワイプの起点を画面左半分（x ≤ innerWidth/2）に広げた。
実機利用で「チャットのところからなら画面左半分ではなく画面全体でいい」とのフィードバックを受けた。

## 選択肢

1. サイドバーを開く右スワイプの起点制限を撤廃する（画面全体）。右パネルから戻る操作は左端 28px のまま。
2. 左半分のまま維持する。

## 決定

選択肢 1。

## 理由

- サイドバーを開くのはチャット表示中（右パネル非展開・ドロワー閉）だけで、横スクロール祖先・編集領域・
  テキスト選択・閾値（|dx| ≥ 60 かつ水平優勢）のガードは起点位置と独立に効くため、撤廃しても誤発火面の増加は小さい。
- 右パネル（diff 等）は横パン操作が主なので、左端限定は 0210 の理由どおり維持する。
- 右半分起点の右スワイプに割り当てた別操作は無く、衝突しない。

## 検証

- `npm test`: 行 7 のテストを「右半分起点でも開く」に更新して通過。
- iPhone PWA 実機で、チャット表示中に画面右半分起点の右スワイプでサイドバーが開き、右パネル表示中は従来どおり左端からのみ戻ることを確認後に accepted とし、ADR-20261024-0210 の status を superseded に更新する。
- 2026-10-26: ユーザーが iPhone PWA 実機で確認（「実機確認完了」）。
